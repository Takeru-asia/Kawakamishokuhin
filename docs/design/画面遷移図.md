# 川上食品 HACCP管理システム 画面遷移図

## 全体構成

```mermaid
flowchart TB
    subgraph 認証
        LOGIN[ログイン画面]
    end

    subgraph メイン
        DASH[ダッシュボード]
    end

    subgraph P1_HACCP["フェーズ1: HACCP対応"]
        subgraph 製造管理
            PROD_LIST[製造実績一覧]
            PROD_NEW[製造実績登録]
            PROD_DETAIL[製造実績詳細]
        end

        subgraph 温度管理
            TEMP_LIST[温度記録一覧]
            TEMP_NEW[温度記録登録]
            TEMP_ALERT[温度異常アラート]
        end

        subgraph ロット管理
            LOT_SEARCH[ロット検索]
            LOT_TRACE[トレーサビリティ]
        end

        subgraph 衛生管理
            HYGIENE_LIST[衛生管理記録一覧]
            HYGIENE_NEW[衛生管理記録登録]
        end
    end

    subgraph P2_COST["フェーズ2: 原価把握"]
        subgraph 目標管理
            TARGET_LIST[製造目標一覧]
            TARGET_SET[目標設定]
            TARGET_ANALYSIS[差異分析]
        end

        subgraph ロス管理
            LOSS_LIST[ロス記録一覧]
            LOSS_NEW[ロス記録登録]
            LOSS_REPORT[ロス分析レポート]
        end
    end

    subgraph マスタ管理
        MASTER_PRODUCT[製品マスタ]
        MASTER_MATERIAL[原材料マスタ]
        MASTER_FACILITY[設備マスタ]
        MASTER_USER[ユーザー管理]
    end

    LOGIN --> DASH

    DASH --> PROD_LIST
    DASH --> TEMP_LIST
    DASH --> LOT_SEARCH
    DASH --> HYGIENE_LIST
    DASH --> TARGET_LIST
    DASH --> LOSS_LIST

    PROD_LIST --> PROD_NEW
    PROD_LIST --> PROD_DETAIL
    PROD_DETAIL --> LOT_TRACE

    TEMP_LIST --> TEMP_NEW
    TEMP_LIST --> TEMP_ALERT

    LOT_SEARCH --> LOT_TRACE

    HYGIENE_LIST --> HYGIENE_NEW

    TARGET_LIST --> TARGET_SET
    TARGET_LIST --> TARGET_ANALYSIS

    LOSS_LIST --> LOSS_NEW
    LOSS_LIST --> LOSS_REPORT

    DASH --> MASTER_PRODUCT
    DASH --> MASTER_MATERIAL
    DASH --> MASTER_FACILITY
    DASH --> MASTER_USER
```

|----|--------|--------|----------|------|
| 1 | LOGIN | ログイン画面 | - | ユーザー認証 |
| 2 | DASH | ダッシュボード | - | システム全体の状況表示 |

| 5 | PROD_DETAIL | 製造実績詳細 | P1 | 製造実績の詳細表示・編集 |
| 6 | TEMP_LIST | 温度記録一覧 | P1 | 温度記録の一覧表示 |
| 7 | TEMP_NEW | 温度記録登録 | P1 | 温度記録の新規登録 |
| 8 | TEMP_ALERT | 温度異常アラート | P1 | 温度異常の通知・対応記録 |
| 9 | LOT_SEARCH | ロット検索 | P1 | ロット番号による検索 |
| 10 | LOT_TRACE | トレーサビリティ | P1 | ロット追跡表示 |
| 11 | HYGIENE_LIST | 衛生管理記録一覧 | P1 | 衛生管理記録の一覧 |
| 12 | HYGIENE_NEW | 衛生管理記録登録 | P1 | 衛生管理記録の登録 |

| 14 | TARGET_SET | 目標設定 | P2 | 製造目標の設定 |

| 22 | MASTER_USER | ユーザー管理 | - | ユーザーアカウント管理 |
