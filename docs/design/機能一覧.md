# 川上食品 HACCP管理システム 機能一覧

## 概要

要件定義書・画面遷移図・ユースケース一覧・エンティティ一覧から導出した機能の一覧。
各機能にユースケースとの対応、関連エンティティ、CRUD種別、実装フェーズを記載する。

**機能種別の定義**:
- **画面**: ユーザーが操作するUI画面
- **API**: フロントエンドから呼び出すバックエンドAPI
- **ロジック**: サーバーサイドのビジネスロジック（自動処理含む）
