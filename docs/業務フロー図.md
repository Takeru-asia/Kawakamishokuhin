## 2. 全体業務フロー

### 2.1 日常業務の全体像

本システムにおける川上食品の1日の業務フローを示す。

```mermaid
flowchart TD
    START([始業]) --> LOGIN[システムにログイン]
    LOGIN --> DASH[ダッシュボードを確認]

    DASH --> CHECK_ALERT{未対応アラート\nあり？}
    CHECK_ALERT -->|あり| ALERT_RESPONSE[温度異常アラート対応\nBF-TEMP-02]
    CHECK_ALERT -->|なし| DAILY_TASKS

    ALERT_RESPONSE --> DAILY_TASKS[日常業務]

    DAILY_TASKS --> MORNING[午前の業務]
    DAILY_TASKS --> AFTERNOON[午後の業務]

    MORNING --> TEMP_AM[温度記録\n冷蔵庫・冷凍庫]
    MORNING --> HYGIENE_AM[衛生点検\n清掃・水質検査]
    MORNING --> PROD_PREP[製造準備\n原材料ロット確認]

    AFTERNOON --> PROD_REG[製造実績登録]
    AFTERNOON --> TEMP_PM[温度記録\n午後巡回]
    AFTERNOON --> LOSS_REG[ロス記録登録]

    TEMP_AM --> REVIEW[管理者レビュー]
    HYGIENE_AM --> REVIEW
    PROD_PREP --> REVIEW
    PROD_REG --> REVIEW
    TEMP_PM --> REVIEW
    LOSS_REG --> REVIEW

    REVIEW --> ANALYSIS{分析業務\n必要？}
    ANALYSIS -->|はい| TARGET_CHECK[目標達成率確認\nBF-TGT-01]
    ANALYSIS -->|はい| LOSS_REPORT[ロスレポート確認\nBF-LOSS-02]
    ANALYSIS -->|いいえ| LOGOUT

    TARGET_CHECK --> LOGOUT[ログアウト]
    LOSS_REPORT --> LOGOUT
    LOGOUT --> END_DAY([終業])
```

## 3. 認証業務フロー

### BF-AUTH-01: ログイン・ログアウト

**対応ユースケース**: UC-AUTH-01（ログイン）、UC-AUTH-02（ログアウト）

```mermaid
flowchart TD
    START([開始]) --> ACCESS[システムにアクセス]
    ACCESS --> HAS_SESSION{有効なセッション\nあり？}

    HAS_SESSION -->|あり| DASHBOARD[ダッシュボード表示]
    HAS_SESSION -->|なし| LOGIN_PAGE[ログイン画面表示]

    LOGIN_PAGE --> INPUT[メールアドレス・\nパスワードを入力]
    INPUT --> SUBMIT[ログインボタン押下]

    SUBMIT --> VALIDATE{入力値\nバリデーション}
    VALIDATE -->|不正| ERROR_INPUT[入力エラー表示]
    ERROR_INPUT --> INPUT

    VALIDATE -->|正常| AUTH{認証処理}
    AUTH -->|失敗| ERROR_AUTH[認証エラー表示\n「メールアドレスまたは\nパスワードが正しくありません」]
    ERROR_AUTH --> INPUT

    AUTH -->|無効ユーザー| ERROR_INACTIVE[エラー表示\n「アカウントが\n無効化されています」]
    ERROR_INACTIVE --> INPUT

    AUTH -->|成功| CREATE_JWT[JWTトークン生成\n有効期限: 8時間]
    CREATE_JWT --> SET_COOKIE[httpOnly Cookieに\nトークン設定]
    SET_COOKIE --> DASHBOARD

    DASHBOARD --> USE_SYSTEM[システム利用]

    USE_SYSTEM --> LOGOUT_CLICK{ログアウト\n押下？}
    LOGOUT_CLICK -->|いいえ| CHECK_EXPIRY{セッション\n期限切れ？}
    CHECK_EXPIRY -->|いいえ| USE_SYSTEM
    CHECK_EXPIRY -->|はい| CLEAR_COOKIE_AUTO[Cookie自動失効]
    CLEAR_COOKIE_AUTO --> LOGIN_PAGE

    LOGOUT_CLICK -->|はい| CLEAR_COOKIE[Cookie削除]
    CLEAR_COOKIE --> LOGIN_PAGE
    LOGIN_PAGE --> END_FLOW([終了])
```

**処理詳細**:

| ステップ | 処理内容 | 関連テーブル |
|---------|---------|-------------|
| 認証処理 | メールアドレスでユーザー検索、bcryptでパスワード照合 | users |
| JWT生成 | HS256署名、ペイロード: userId, email, role, name | - |
| Cookie設定 | httpOnly, Secure, SameSite=Lax, Path=/, MaxAge=28800秒 | - |
| ログアウト | Cookie削除（MaxAge=0） | - |

## 5. 温度管理業務フロー

### BF-TEMP-01: 温度記録・異常検知

**対応ユースケース**: UC-TEMP-01（温度記録一覧閲覧）、UC-TEMP-02（温度記録）

```mermaid
flowchart TD
    START([温度計測開始]) --> SELECT_FACILITY[設備を選択\n冷蔵庫A / 冷蔵庫B /\n冷凍庫 / 加熱設備]

    SELECT_FACILITY --> MEASURE[温度を計測]
    MEASURE --> INPUT_TEMP[計測温度を入力]
    INPUT_TEMP --> INPUT_NOTES[備考を入力\n任意]

    INPUT_NOTES --> SUBMIT[登録ボタン押下]

    SUBMIT --> VALIDATE{入力値\nバリデーション}
    VALIDATE -->|不正| ERROR[エラー表示]
    ERROR --> INPUT_TEMP

    VALIDATE -->|正常| FETCH_FACILITY[設備の温度基準値\nを取得]

    FETCH_FACILITY --> CHECK_TYPE{設備種別は？}

    CHECK_TYPE -->|冷蔵設備\n冷凍設備| CHECK_UPPER{計測温度 >\n上限値？}
    CHECK_TYPE -->|加熱設備| CHECK_LOWER{計測温度 <\n下限値？}
    CHECK_TYPE -->|その他| NORMAL[正常と判定]

    CHECK_UPPER -->|はい| ABNORMAL[異常と判定]
    CHECK_UPPER -->|いいえ| NORMAL

    CHECK_LOWER -->|はい| ABNORMAL
    CHECK_LOWER -->|いいえ| NORMAL

    NORMAL --> SAVE_NORMAL[温度記録を保存\nis_normal = true]
    SAVE_NORMAL --> SUCCESS[登録完了\n一覧画面へ遷移]

    ABNORMAL --> SAVE_ABNORMAL[温度記録を保存\nis_normal = false]
    SAVE_ABNORMAL --> CREATE_ALERT[温度アラートを\n自動作成\nstatus = OPEN]
    CREATE_ALERT --> ALERT_NOTIFY[ダッシュボードに\nアラートバナー表示]
    ALERT_NOTIFY --> SUCCESS

    SUCCESS --> VIEW_LIST{一覧を\n確認？}
    VIEW_LIST -->|はい| LIST[温度記録一覧表示\n日付・設備フィルタ]
    VIEW_LIST -->|いいえ| END_FLOW([終了])
    LIST --> END_FLOW
```

**温度異常検知ルール**:

| 設備種別 | 基準値 | 異常判定条件 | 例 |
|---------|--------|------------|-----|
| 冷蔵設備 (REFRIGERATOR) | 上限 5.0℃ | 計測温度 > 上限値 | 8.5℃ → 異常 |
| 冷凍設備 (FREEZER) | 上限 -15.0℃ | 計測温度 > 上限値 | -10.0℃ → 異常 |
| 加熱設備 (HEATER) | 下限 75.0℃ | 計測温度 < 下限値 | 60.0℃ → 異常 |
| その他 (OTHER) | なし | 常に正常 | - |

### BF-TEMP-02: 温度異常アラート対応

**対応ユースケース**: UC-TEMP-03（アラート一覧閲覧）、UC-TEMP-04（温度異常対応）

```mermaid
flowchart TD
    START([アラート管理\n画面を開く]) --> LOAD_LIST[アラート一覧を取得]

    LOAD_LIST --> FILTER{ステータスで\nフィルタ？}
    FILTER -->|全件| SHOW_ALL[全アラート表示]
    FILTER -->|未対応| SHOW_OPEN[OPENのみ表示]
    FILTER -->|確認済み| SHOW_ACK[ACKNOWLEDGEDのみ表示]
    FILTER -->|解決済み| SHOW_RES[RESOLVEDのみ表示]

    SHOW_ALL --> SELECT_ALERT
    SHOW_OPEN --> SELECT_ALERT
    SHOW_ACK --> SELECT_ALERT
    SHOW_RES --> SELECT_ALERT

    SELECT_ALERT[アラートを選択] --> CHECK_ROLE{ユーザー\nロールは？}

    CHECK_ROLE -->|WORKER| VIEW_ONLY[閲覧のみ\nステータス変更不可]
    VIEW_ONLY --> END_FLOW([終了])

    CHECK_ROLE -->|MANAGER\nADMIN| CAN_UPDATE[ステータス変更可能]

    CAN_UPDATE --> CURRENT_STATUS{現在の\nステータスは？}

    CURRENT_STATUS -->|OPEN| ACK_OR_RESOLVE{対応内容}
    ACK_OR_RESOLVE -->|確認のみ| SET_ACK[ステータスを\nACKNOWLEDGED\nに変更]
    ACK_OR_RESOLVE -->|是正完了| INPUT_ACTION_1[是正措置を入力]
    INPUT_ACTION_1 --> SET_RESOLVED_1[ステータスを\nRESOLVED\nに変更]

    CURRENT_STATUS -->|ACKNOWLEDGED| INPUT_ACTION_2[是正措置を入力]
    INPUT_ACTION_2 --> SET_RESOLVED_2[ステータスを\nRESOLVED\nに変更]

    CURRENT_STATUS -->|RESOLVED| ALREADY_DONE[対応済み\n変更不要]
    ALREADY_DONE --> END_FLOW

    SET_ACK --> SAVE[保存処理]
    SET_RESOLVED_1 --> SAVE
    SET_RESOLVED_2 --> SAVE

    SAVE --> RECORD_RESOLVER[対応者・対応日時\nを自動記録]
    RECORD_RESOLVER --> UPDATE_DASH[ダッシュボードの\nアラートバナー更新]
    UPDATE_DASH --> END_FLOW
```

## 6. 製造管理業務フロー

### BF-PROD-01: 製造実績登録

**対応ユースケース**: UC-PROD-01（一覧閲覧）、UC-PROD-02（登録）、UC-PROD-03（詳細閲覧）

```mermaid
flowchart TD
    START([製造実績\n登録開始]) --> INPUT_DATE[製造日を入力]

    INPUT_DATE --> ADD_ITEM[明細行を追加]

    ADD_ITEM --> SELECT_PRODUCT[製品を選択\n絹ごし豆腐 / 木綿豆腐 /\n厚揚げ / 油揚げ]
    SELECT_PRODUCT --> INPUT_QTY[製造数量を入力]

    INPUT_QTY --> MORE_ITEMS{他の製品も\n登録する？}
    MORE_ITEMS -->|はい| ADD_ITEM
    MORE_ITEMS -->|いいえ| INPUT_NOTES[備考を入力\n任意]

    INPUT_NOTES --> SUBMIT[登録ボタン押下]

    SUBMIT --> VALIDATE{入力値\nバリデーション}
    VALIDATE -->|不正| ERROR[エラー表示\n「明細を1件以上\n入力してください」等]
    ERROR --> ADD_ITEM

    VALIDATE -->|正常| SAVE_HEADER[製造実績ヘッダー保存\nproduction_records]
    SAVE_HEADER --> SAVE_ITEMS[製造実績明細保存\nproduction_record_items]

    SAVE_ITEMS --> LOOP_ITEMS[各明細行に対して\n以下を繰り返し]

    LOOP_ITEMS --> GEN_LOT_NUM[ロット番号を\n自動採番]

    subgraph ロット自動採番
        GEN_LOT_NUM --> GET_DATE[製造日を取得\nYYYYMMDD形式]
        GET_DATE --> GET_SEQ[当日の最終連番を取得]
        GET_SEQ --> CALC_NEXT[次の連番を算出\n+1]
        CALC_NEXT --> FORMAT[PLT-YYYYMMDD-NNN\n形式で生成]
    end

    FORMAT --> CREATE_LOT[製品ロットを作成\nproduct_lots]
    CREATE_LOT --> NEXT_ITEM{次の\n明細行は？}
    NEXT_ITEM -->|あり| LOOP_ITEMS
    NEXT_ITEM -->|なし| COMPLETE[登録完了]

    COMPLETE --> REDIRECT[製造実績一覧へ遷移]
    REDIRECT --> VIEW_DETAIL{詳細を\n確認？}
    VIEW_DETAIL -->|はい| DETAIL[製造実績詳細表示\n明細・ロット番号表示]
    VIEW_DETAIL -->|いいえ| END_FLOW([終了])
    DETAIL --> END_FLOW
```

**ロット番号採番ルール**:

| 項目 | 内容 |
|------|------|
| 形式 | `PLT-YYYYMMDD-NNN` |
| 例 | `PLT-20260209-001`、`PLT-20260209-002` |
| 連番リセット | 日付が変わると001から再開 |
| 重複制御 | 同日の最終連番+1で新規採番 |

```mermaid
flowchart TD
    START([製造実績\n編集開始]) --> LIST[製造実績一覧画面]
    LIST --> SELECT[対象の製造実績を選択]

```
