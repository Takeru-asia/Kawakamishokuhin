# 川上社長への確認事項（2026-10-09）

出典: 10/9 打ち合わせ / 2/17 ご要望 / アプリ内フィードバック（10/8・10/9）
各項目は「はい／いいえ」または (a)(b) の選択でお答えください。

## 1. 入室時の写真（服装チェック）
写真の保存先・保持期間・確認方法が決まり次第、iPad のカメラで撮影して保存する機能を作ります。
それまでは「出勤時チェック」画面の 帽子 / マスク / 作業着 のチェック欄で代替しています。

1-1. 写真の保持期間はどれにしますか。
  (a) 30 日で自動削除（当方の推奨。従業員の個人情報のため） (b) 1 年 (c) 無期限
1-2. 写真を確認するのは誰ですか。
  (a) 責任者が毎日一覧で確認する (b) 問題があった時だけ見返す
1-3. 帽子・マスクの着用を自動で判定する機能は不要で、目視確認の記録でよいですか。（はい／いいえ）

## 2. 製品マスタ
現在の有効な製品は、社長が登録された 木綿豆腐 / 絹ごし豆腐 / 厚揚げ / ゆし豆腐 / 焼き豆腐 / ソフト豆腐 です。
これに コープもめん / コープゆしどうふ / コープ厚揚げ / 厚揚げ生地 を追加しました。
10/9 に挙げていただいた「もめん」「ゆしどうふ」「絹ごし」は、既存の 木綿豆腐 / ゆし豆腐 / 絹ごし豆腐 を使う前提にしています。

2-1. この対応でよいですか。（はい／いいえ）
2-2. 製品名を「もめん」「ゆしどうふ」「絹ごし」に揃えますか。（はい／いいえ。はい の場合は当方で変更します）
2-3. 各製品の単位（パック / 丁 / 枚）で直したいものがあれば教えてください。

## 3. 大豆の仕込み数量
一般大豆 / コープロ大豆 / 絹ごし用大豆 の 3 種を kg で入力する形で実装しました。

3-1. 単位は kg でよいですか。（はい／いいえ）
3-2. 「仕込み数量」は前日に浸漬する量という理解でよいですか。当日の使用実績であれば別の欄にします。（はい／いいえ）

## 4. 残留塩素の管理基準
0.1 mg/L 以上を合格として実装しました（水道法の基準）。

4-1. HACCP 計画で別の基準値を定めていれば教えてください。なければ「このままでよい」とお答えください。
