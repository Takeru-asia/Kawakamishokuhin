## Q1. 入室時の写真（服装チェック）— 実装保留中

**何が未確定か**
- 写真の保存先と費用（クラウドストレージの追加契約が必要）
- 従業員の写真の保持期間（個人情報。例: 30日で自動削除 / 1年 / 無期限）
- 誰がいつ確認するか（責任者が毎日一覧で見る / 問題時だけ見返す）
- 自動判定（帽子・マスクの着用を AI が判定）が必要か、目視確認の記録でよいか

**どう答えれば進められるか**

- 先行して「出勤時チェック」画面に 帽子 / マスク / 作業着 / 手洗い のチェック欄を入れておく（写真なし）
