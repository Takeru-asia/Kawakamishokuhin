## バックログアイテム

### 優先度凡例（MoSCoW法）

| 優先度 | 説明 |
|--------|------|
| **Must** | 必須。リリースに不可欠な機能 |
| **Should** | 重要。可能な限り含めるべき機能 |
| **Could** | あると良い。余裕があれば実装する機能 |
| **Won't** | 今回は対象外。将来バージョンで検討 |
