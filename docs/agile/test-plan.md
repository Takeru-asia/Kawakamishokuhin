## 1. テスト戦略

### 1.1 テストレベル

| レベル | 目的 | ツール | カバレッジ目標 |
|--------|------|--------|-------------|
| ユニットテスト | 個々の関数・バリデーションロジックの検証 | Vitest | 80%以上 |
| 統合テスト | Server Action・API Route・DB連携の検証 | Vitest + Prisma Test | 70%以上 |
| E2Eテスト | ユーザーシナリオ全体の動作検証 | Playwright | 主要フロー100% |
| 手動テスト | UI/UX確認、レスポンシブ、クロスブラウザ | - | 全画面 |

### 1.2 テスト方針

- **Shift Left:** 開発初期からユニットテストを実施
- **リスクベース:** HACCP関連（温度異常検出、ロットトレース）を重点テスト
- **自動化優先:** CI/CDパイプラインで自動テストを実行
- **境界値分析:** 温度閾値、数量、日付範囲の境界条件を網羅
