# リリースノート

## 川上食品 HACCP管理システム

---

## v1.0.0（初回リリース）

**リリース日:** 2026-02-09

**概要:** 川上食品 HACCP管理システムの初回リリース。HACCP管理の基本機能（Phase 1）および原価管理機能（Phase 2）を含む、豆腐製造工場向けの統合品質管理システム。

---

### 新機能

#### Phase 1: HACCP管理

**ダッシュボード**
- KPIカード（本日製造数量、衛生検査合格率、ロス率、温度異常件数）のリアルタイム表示
- 温度異常アラートバナーによる即時通知
- 過去7日間の製造実績棒グラフ（Recharts）
- 全設備の最新温度ステータス一覧
- クイックアクションボタン（製造登録、温度記録、ロット検索、衛生記録）
- SWRによる30秒間隔の自動データ更新

**製造実績管理**
- 製造実績の登録（複数製品の明細対応）
- 製品ロットの自動採番（PLT-YYYYMMDD-NNN形式）
- 製造実績一覧の日付検索
- 製造実績詳細表示（明細・ロット情報含む）

**温度管理**
- 設備の温度記録登録
- 温度異常の自動検出（設備閾値との比較）
- 異常時のアラート自動生成
- アラート管理（確認・是正措置記録・解決）
- 温度記録の設備別・日付別検索

**ロットトレーサビリティ**
- 製品ロット検索（ロット番号・製品名での部分一致検索）
- 原材料ロット登録（自動採番: MLT-YYYYMMDD-NNN形式）
- 原材料ロットと製品ロットの紐付け登録
- 前方トレース（原材料 → 製品の追跡）
- 後方トレース（製品 → 原材料の追跡）
- ロット詳細表示（製品ロット/原材料ロット）

**衛生管理**
- 衛生管理記録の登録（PASS/FAIL/NA判定）
- 衛生管理記録のカテゴリ別・日付別検索
- 4つの衛生管理カテゴリ（清掃、害虫駆除、水質検査、廃棄物管理）

#### Phase 2: 原価管理

**製造目標管理**
- 月次製造目標の設定（製品別）
- 製造目標一覧の年月・製品別検索
- 目標の編集・削除
- 目標達成率分析（目標数量 vs 実績数量の比較）

**ロス管理**
- ロス記録の登録（ロス率自動計算）
- ロス記録の製品別・カテゴリ別・日付別検索
- 期間ロスレポート（カテゴリ別集計、製品別集計、全体ロス率）
- Rechartsによるグラフ表示

#### マスタ管理

**製品マスタ**
- 製品の登録・更新・論理削除
- コード重複チェック

**原材料マスタ**
- 原材料の登録・更新・論理削除
- 仕入先情報の管理

**設備マスタ**
- 設備の登録・更新・論理削除
- 設備種別（冷蔵庫/冷凍庫/加熱設備/その他）
- 温度上限・下限閾値の設定

**ユーザー管理**
- ユーザーの登録・更新・論理削除
- ロールベースアクセス制御（ADMIN/MANAGER/WORKER）
- パスワードのbcryptハッシュ化
- 自己削除防止機能

#### 認証・セキュリティ

- JWT認証（HS256、8時間有効）
- httpOnly Cookie によるトークン管理
- Middleware による全ルート保護
- ロールベースアクセス制御

### 既知の問題

| ID | 内容 | 重要度 | 回避策 |
|----|------|--------|--------|
| KI-001 | 製造実績の編集・削除機能が未実装 | 中 | 誤入力時はDB直接操作で修正 |
| KI-002 | ページネーションが一部画面で未対応（件数制限のみ） | 低 | 検索条件で絞り込み |
| KI-003 | ダッシュボードの直近アクティビティAPIは使用されているがUIに未表示 | 低 | APIは利用可能 |
| KI-004 | パスワードリセット機能が未実装 | 中 | 管理者がユーザー管理画面からパスワードを変更 |
| KI-005 | JWT_SECRETがデフォルト値のまま使用される可能性 | 高 | 本番環境では必ず変更すること |
| KI-006 | 製品ロット自動採番時の同時実行による番号競合リスク | 低 | 通常運用では問題なし |
